# Changelog

All notable changes to Pages Converter are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-21

### Added

- Batch conversion from `.pages` to `.docx` using local LibreOffice.
- Recursive folder selection with preserved directory structure.
- Pass-through copying for non-Pages files.
- Live progress percentage, current filename, and conversion statistics.
- ZIP output with `conversion-errors.txt` for failures.
- Local-only server bound to `127.0.0.1`.
- Persian responsive interface with light and dark themes.
- Windows launcher with Python and LibreOffice checks.
