# Pages Converter — راهنمای فارسی

Pages Converter یک ابزار لوکال برای تبدیل گروهی فایل‌های Apple Pages در ویندوز است.

## امکانات

- تبدیل فایل‌های `.pages` به `.docx`
- انتخاب یک پوشه کامل همراه با تمام زیرپوشه‌ها
- حفظ ساختار پوشه‌بندی در ZIP خروجی
- کپی فایل‌های PDF، Word، تصویر و سایر پسوندها بدون تغییر
- نمایش درصد پیشرفت، فایل جاری و آمار تبدیل/کپی/خطا
- اجرای کاملاً لوکال بدون ارسال فایل‌ها به اینترنت
- نگه‌داشتن فایل اصلی Pages در صورت ناموفق بودن تبدیل

## پیش‌نیازها

- Windows 10 یا 11
- Python 3.10 یا جدیدتر
- آخرین نسخه LibreOffice
- مرورگر Chrome یا Edge

## اجرا

1. Python را نصب و گزینه **Add Python to PATH** را فعال کنید.
2. LibreOffice را نصب کنید.
3. روی `start.bat` دوبار کلیک کنید.
4. پوشه اصلی را انتخاب کنید.
5. دکمه پردازش و دانلود ZIP را بزنید.

برنامه فقط روی آدرس `127.0.0.1` اجرا می‌شود و فایل‌ها از سیستم شما خارج نمی‌شوند.

> تبدیل توسط LibreOffice انجام می‌شود؛ بنابراین ممکن است چیدمان فایل‌های Pages پیچیده کمی تغییر کند.
